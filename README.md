# Hi, I'm Abdullah Khan 👋

Software developer focused on building practical full-stack, desktop, and internal business applications.

I have experience across web development, backend systems, databases, internal tools, and hardware-connected desktop software. Alongside software development, I am building hands-on skills in cybersecurity, networking, Windows systems, and security operations.

## What I Work With

* **Frontend:** React, Next.js, TypeScript, Tailwind CSS
* **Backend:** Node.js, Express, REST APIs
* **Databases:** PostgreSQL, Prisma, MongoDB, SQL Server
* **Desktop Applications:** Electron, Node.js
* **Systems & Infrastructure:** Linux, Windows Server, Active Directory, DNS, DHCP
* **Cybersecurity Learning:** SOC fundamentals, networking, Windows event logs, log analysis, TryHackMe labs

## Selected Work

* **Load Test Monitor** — Electron desktop application for monitoring industrial load tests through RS-485/Modbus RTU, with real-time charting, CSV/PDF report generation, calibration records, and a licensing workflow.
* **Exam Portal** — Full-stack examination platform built with Next.js, Prisma, PostgreSQL, authentication, payments, test generation, and results management.
* **QMS & Internal Business Tools** — Process-driven systems for quality documentation, records, workflows, and SQL-based data management.
* **Web Applications** — Projects involving e-commerce, payments, role-based access, authentication, APIs, and deployment.

## Current Focus

* Building production-ready full-stack and desktop applications
* Improving backend architecture, databases, deployment, and system design
* Developing practical Blue Team / SOC cybersecurity skills through hands-on labs
* Creating projects that combine software development, infrastructure, and security
